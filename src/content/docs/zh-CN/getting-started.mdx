## 安装前先了解

NextMail 正式版支持 Windows 10 22H2+ x64、macOS 12+ 的 Intel 和 Apple Silicon 设备，以及 Linux x64。

请在[下载页](/zh-CN/download/)选择对应架构的安装文件。每个链接均指向官方 GitHub 仓库实际发布的资产。

> Windows 尚未使用正式代码签名。macOS 使用 ad-hoc 签名，尚未通过 Apple 公证。系统可能显示“开发者未经验证”等提示，请只从官方仓库下载。

## 选择邮件存放位置

首次启动时，可以选择本地数据目录。NextMail 会把邮件数据库和下载的内容存放在这里；账户密码单独保存在操作系统的安全凭据库中。

本地优先不代表所有正文都已经下载。保存在设备上的内容可以本地读取；新的正文和附件默认按需获取。

## 添加第一个账户

NextMail 使用 **IMAP 和 SMTP 密码认证**连接邮箱。部分服务商需要应用专用密码或授权码，也可能要求先在网页邮箱中开启 IMAP/SMTP。

自动发现会尝试为常见邮箱和自有域名建议服务器设置，你也可以手动调整。识别到服务器不代表服务商一定允许密码认证。目前尚未实现 OAuth 登录。

## 让邮件逐步到达

NextMail 会先建立文件夹树，再逐步同步邮件。发件人、主题、状态、附件信息和简短预览先到达；打开邮件才获取正文，打开或保存某个附件才下载这个文件。

接下来可以了解[账户设置](/zh-CN/docs/accounts/)，或看看[同步机制](/zh-CN/docs/sync/)。
